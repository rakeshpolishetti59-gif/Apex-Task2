02

Add JavaScript Form Validation

Real-time and submit-time client-side verification ensuring data cleanliness before submission.

Rule 1

Required Field Validation

Inspects input elements for empty or whitespace-only values using .trim() === ''. Instantly adds .is-invalid class to highlight missing fields.

if (nameInput.value.trim() === '') { showError('Name is required'); }
Rule 2

Email Format Verification

Tests the email string against a regular expression pattern to guarantee user input includes username, domain, and top-level extension (e.g. user@example.com).

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
Rule 3

Dynamic Error & Success UI

Clears error messages automatically when the user starts typing (via input listeners) and surfaces a high-contrast success banner on successful validation.

input.addEventListener('input', () => clearError(input));

Responsive Breakpoint Strategy

Media queries guarantee fluidity across Mobile (<640px), Tablet (640px–1024px), and Desktop (>1024px).

Device Target Breakpoint Rule Layout Adaptation Flex / Grid Application
Mobile @media (max-width: 640px) Single column stack, full-width inputs, collapsed hamburger navigation flex-direction: column / grid-template-columns: 1fr
Tablet @media (max-width: 1024px) 2-column grid cards, condensed spacing, touch-friendly tap targets grid-template-columns: repeat(2, 1fr)
Desktop @media (min-width: 1025px) Full multi-column layout, sticky navigation bar, generous padding grid-template-columns: repeat(3, 1fr)

DOM Manipulation Under the Hood

How JavaScript handles dynamic document modifications in memory.

  • DOM
    Creating Dynamic Nodes:

    document.createElement('li') generates fresh HTML elements in browser memory before mounting them into the document tree.

  • EVENT
    Event Listeners & Delegation:

    Listening for click, change, and keydown allows users to trigger tasks seamlessly by hitting Enter or clicking buttons.

  • TREE
    Appending & Removing Elements:

    parentElement.appendChild(newElement) attaches items to the list, while element.remove() completely detaches them from the DOM.

  • CLASS
    Toggling CSS State Classes:

    classList.toggle('completed') applies strikethrough styling and updates accessibility attributes dynamically.
